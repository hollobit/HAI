hai 대시보드 전반에서 사용되는 22개 AI 용어의 한국어 정의. Stanford HAI AI Index · Epoch AI · 산업 표준 기준.

compute

FLOPs 부동소수점 연산
Floating Point Operations. AI 모델 학습 compute 의 표준 단위. GPT-4 학습 ~2×10²⁵ FLOPs 추정.
GPU 그래픽 처리 장치
병렬 행렬 연산 특화 칩. NVIDIA H100/B100 가 시장 80%+. 한국 GPU 자체 생산 0, 삼성 HBM 만 공급.
TPU 텐서 처리 장치
Google 자체 설계 AI 가속 칩. v6 (Trillium) 까지 출시. Gemini 학습용. AWS/Azure 는 자체 칩 (Trainium/Maia) 추진.
HBM 고대역폭 메모리
High-Bandwidth Memory. GPU 옆에 적층된 초고속 D램. NVIDIA H100/B100 의 핵심 부품. 삼성/SK하이닉스 글로벌 공급 ~90%.

거버넌스

RAI 책임있는 AI
Responsible AI. 편향·안전·투명성·프라이버시 등을 고려한 AI 개발/배포. 연구 논문 수가 2019-2025 10×↑.

경제

AI Diffusion AI 확산
기업·일상에서 AI 활용 도입률. Stanford H2 2025 글로벌 ~30%. 한국 (서비스업 위주) 확산 가속 중.
AI Talent Concentration AI 인재 집중도
LinkedIn 기반 노동인구 중 AI 스킬 보유 비율. 미·이스라엘·인도 상위. 한국 11/12 peers (Stanford 2026).

기술

RAG 검색 증강 생성
Retrieval-Augmented Generation. LLM 답변 시 외부 지식 베이스 검색해 활용. 환각 감소 + 최신 정보 반영.
Agent 에이전트
LLM + 도구 (코드 실행 · 웹 검색 · API 호출) 결합으로 자율적 작업 수행. 2025 SWE-bench · Scientific Agents 등 벤치마크 등장.

모델

Foundation Model (FM) 파운데이션 모델
대규모 데이터로 사전 학습된 범용 AI 모델. 단일 모델이 다수의 다운스트림 태스크에 적용 가능 (LLM 이 대표). GPT, Claude, Gemini 등.
LLM 대규모 언어 모델 (Large Language Model)
수십억-수조 파라미터의 transformer 기반 언어 모델. 텍스트 생성·추론·코드 작성 등 범용 태스크 수행. GPT-4, Claude 4 등.
Notable Model 주목할 만한 ML 모델
Stanford HAI / Epoch AI 가 추적하는 frontier ML 모델 — 영향력 · 성능 · 학습 compute 기준. 2025 누적 1,000+ 모델.
Context Window 컨텍스트 길이
한 번의 입력에 모델이 처리할 수 있는 토큰 수. 2022 4K → 2024 1M (Gemini 1.5 Pro) → 2025 2M+. 긴 문서 분석 가능.

벤치마크

MMLU Massive Multitask Language Understanding
57 학문 영역 객관식 문제 (~14,000개). 대표 LLM 능력 평가 벤치마크. 2025 frontier 모델 ~92% (인간 89%).
GPQA 박사급 과학 QA
Graduate-level Physics, Chemistry, Biology QA. 비전공자가 google 해도 풀기 어려운 박사급 문제. 2025 o3 ~85%.
SWE-bench 소프트웨어 엔지니어링 벤치마크
실제 GitHub repo 의 issue 를 코드로 해결하는 능력 측정. 2024 12% → 2025 70%+ 폭증.
Arena Elo 챗봇 아레나 Elo
LMSYS Chatbot Arena 의 인간 페어 비교 기반 Elo 점수. 모델 간 일대일 사용자 선호 측정. 2025 frontier ~1400+.

아키텍처

Transformer 트랜스포머
2017년 Google 'Attention is All You Need' 에서 도입된 self-attention 기반 아키텍처. 현 모든 frontier LLM 의 기본 구조.

정책

AI Act AI 법
EU 의 2024 종합 AI 규제법. risk-tier 기반 (unacceptable/high/limited/minimal). 한국 'AI 기본법' 2024 12월 통과.
AI Safety Institute AI 안전 연구소
국가 단위 frontier AI 안전 평가 기관. 영국·미국 (NIST) 가 시작. 한국은 2025 신설 발표.

토큰 경제

Token 토큰
LLM 의 텍스트 처리 단위 (≈ 0.75 단어). 가격 단위. 2022 GPT-3.5 turbo $20/M output → 2024 GPT-4o-mini $0.6/M = 33×↓.
Inference 추론
학습된 모델을 사용해 새 입력에 응답 생성. 학습 compute 의 1/1000 정도. 2025 추론 비중이 학습 비중을 추월하는 중.
