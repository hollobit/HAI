왜 판본마다 값이 달라지나

  1. 출처 확장 — Stanford는 매년 새 데이터 제공자(Crunchbase · Quid · CapitalIQ 등)를 통합하거나 커버리지를 확대합니다.
  2. 재분류 — 기업이 사후에 "Generative AI" 회사로 재분류되면 과거 투자액이 해당 카테고리로 이동합니다.
  3. 방법론 개선 — 초기판은 단순 합산, 후속판은 중복 제거·통화 환산·시점 조정.
  4. 데이터 정정 — 원 데이터 제공자가 에러를 수정하면 신판이 반영.

이 드리프트는 오류가 아니라 업데이트입니다. 대시보드는 최신 판본(2026)의 값을 기본으로 사용하되, 정책 인용 시 "2026판 기준"임을 명시하는 것이 안전합니다.
