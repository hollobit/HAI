📐 계산 방식 · 프리셋 · URL 공유

랭크 스코어

각 차원: rank_score = (total − korea_rank + 1) / total × 100. 0 = 꼴찌, 100 = 1위.

가중평균

overall = Σ(rank_score × weight) / Σ(weight). 가중치는 0.5–2.0 슬라이더로 조정 가능.

값 시뮬레이션

슬라이더 조정 시 korea_value × (1 + adj/100) 로 새 값을 계산하고, 기존 top10 peer 중 새 값을 초과하는 국가 수를 다시 세서 가상 순위를 매깁니다 (top10 범위 내).

프리셋 의도

  • HAI 기본 — 기존 9 차원, LLM 스코어카드와 비교 가능
  • 투자 중심 — 민간 투자·기업·인재 관점 (한국 최약점 노출)
  • 연구 중심 — 모델·특허·논문 (한국 중위권 강점)
  • 배치 중심 — 기업 확산·규제·신뢰 (현장 관점)

URL 공유

모든 상태가 URL 쿼리로 동기화됩니다. 예: ?preset=investment&adj=50,100,0,0,0,0,0,0,0 는 투자 중심 프리셋 + 첫 두 dim 을 50% / 100% 올린 시나리오. 링크를 공유하면 동일한 시뮬레이션이 재현됩니다.
