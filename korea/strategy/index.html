B. 시뮬레이터

C. 권고 — 격차 축소를 위한 개선 배율

  1. 민간 AI 투자 (누적 2013-2025) — 한국이 미국 수준 도달하려면 현재 값을 약 ×70.4 배 ( +6943% ) 개선 필요
  2. 주목할 AI 모델 수 (2025) — 한국이 미국 수준 도달하려면 현재 값을 약 ×10.0 배 ( +900% ) 개선 필요
  3. 산업 로봇 설치 (천대) — 한국이 중국 수준 도달하려면 현재 값을 약 ×9.6 배 ( +864% ) 개선 필요
  4. AI 수용도 (동의율) — 한국이 중국 수준 도달하려면 현재 값을 약 ×1.3 배 ( +30% ) 개선 필요
  5. AI 정책 성숙도 (2025) — 한국이 호주 수준 도달하려면 현재 값을 약 ×1.0 배 ( +0% ) 개선 필요

⚠️ 이 권고는 peer 최댓값 기준 절대 격차를 선형으로 본 계산입니다. 실제 정책 설계는 산업 구조, 국가 규모 (1인당 지표인지 절대 지표인지), 시차, 투자 효율 등을 함께 봐야 합니다. /top3/ 의 LLM 기반 스코어카드는 이 요소들을 정성 반영한 다른 관점입니다.

스코어 계산 방식
  1. dimension_score = value / max(peer values) × 100, 0..100 clamp
  2. overall_score = mean(available dimension scores) — 결측 차원은 분모에서 제외
  3. 슬라이더는 한국 값에 ×(1 + pct/100) 를 곱해 재계산
  4. compute-proxy, ai-publications-cs 는 2026 판 Stanford CSV에 국가별 데이터가 없어 시뮬레이터 대상에서 제외됨

이 로직은 pipeline/src/aiindex_pipeline/korea/scoring.py 에 canonical 로 정의되어 있고, web/src/lib/scoring.ts 가 byte-identical 포팅 (parity 테스트로 강제).
