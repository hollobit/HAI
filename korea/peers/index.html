계산 방식 · Methodology

정규화 (radar): value / max(peer values in available) × 100. 각 차원에서 가용한 peer 값 중 최댓값을 100 으로 설정해 상대 스코어를 계산합니다. 이는 내부 비교 계산이며 Stanford HAI 공식 점수가 아닙니다.

결측 ("—"): Stanford public CSV 에 해당 peer-차원 조합 데이터가 없을 때 표시됩니다. Radar 에서는 해당 차원에 0 을 사용합니다.

가용 배지 "⚠️": 차원에 가용한 peer 가 6개 미만 (insufficient) 임을 뜻합니다. 이 데이터셋에서는 ai-publications-cs 와 compute-proxy 가 해당 — 2026 판 Stanford CSV 에 국가별 breakdown 이 없습니다.
