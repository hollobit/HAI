🔌 AI 유틸리티 스택 분석

AI 는 전기처럼 작동하는 다목적 지능형 에너지 인프라입니다. 발전소(전력망)에서 시작해 변환기(GPU/TPU)·송전망(클라우드)·전기 제품(LLM/FM)을 거쳐 가정용 콘센트(토큰)에 도달하고, 산업 전반(지능형 경제)을 가동시킵니다. 6 레이어 중 어느 하나라도 병목이면 전체 스택이 정체됩니다.

Layer 1

⚡ 전력망

Power Grid

데이터센터 전력 사용이 AI 학습 폭증으로 2030년 945TWh로 확대 예상.

📍 현황

2024 전 세계 데이터센터 전력 사용 ~415TWh, 전체 전력의 1.5%. AI/암호화폐가 절반 이상 차지.

🔮 전망 (2027–2030)

IEA: 2026년 ~620TWh → 2030년 ~945TWh. 학습 vs 추론 비중 역전 (현재 학습 80%, 2030년 추론 70%로).

🇰🇷 한국 위치

한국 데이터센터 전력 사용 ~7TWh (2024). 정부 'AI 컴퓨팅 인프라 확보 전략'으로 GW급 신규 투자 추진. 발전 용량 제약이 GPU 수요 대비 부족 — 핵심 병목.

🔗 스택 내 역할

모든 컴퓨팅의 시작점. 전력 부족 → GPU 가동 불가 → 모델 학습 불가의 캐스케이드.

Computing Infrastructure (GPU / TPU)

NVIDIA H100/B100 시장 80%+ 점유, TPU v6 / AMD MI300 추격 시도 중.

📍 현황

NVIDIA 데이터센터 매출 분기 ~$30B (2025 Q4). H100 → B100 (Blackwell) 전환 중. AI 학습 1회당 GPU 수만~수십만개 필요.

🔮 전망 (2027–2030)

2027년 수요 200% 성장 예상. 칩 공급 병목 vs 다이버시티 (TPU·AMD·Cerebras·Groq) 경쟁.

🇰🇷 한국 위치

한국 GPU 자체 생산 0. 삼성 HBM (HBM3E·HBM4) 으로 NVIDIA 가치사슬 핵심 공급. 자국 NPU (사피온·Rebellions) 노력은 초기 단계.

🔗 스택 내 역할

AI 학습·추론의 물리적 수단. GPU 부족 → 모델 학습 비용 ↑ → 신규 모델 출시 지연.

Layer 5

💰 토큰 경제

Token Economy

추론 비용 GPT-3.5 대비 33배 하락 (2022 출력 $20/M → 2024 GPT-4o-mini 출력 $0.6/M). frontier 모델은 정체, 효율 모델은 급락.

📍 현황

2026 토큰 가격 분포: GPT-4o-mini $0.15/$0.60 (input/output) · Gemini 1.5 Flash $0.075/$0.30 · Claude Sonnet 4 $3/$15 · Claude Opus 4.6 $15/$75. Open-source (DeepSeek-V3 $0.27/$1.10) 가 상용 frontier 가격을 압박. ChatGPT 일일 활성 5억+, 일일 토큰 처리량 글로벌 ~수십조.

🔮 전망 (2027–2030)

2027년 small-tier 토큰 추가 5-10×↓ 예상 → 토큰이 사실상 '공짜'에 근접. Frontier 가격 (o1 · Opus class) 은 reasoning compute 증가로 정체 또는 상승. Open-source 와 closed frontier 가격 격차 좁아지는 중.

🇰🇷 한국 위치

한국 토큰 소비량 글로벌 5-7위 추정. Naver HyperCLOVA · Kakao Konan · Upstage Solar 가 자국 추론 인프라 운영. 가격 경쟁력은 미국 (OpenAI/Anthropic) vs 중국 (DeepSeek) vs 자국 모델 간 trade-off.

🔗 스택 내 역할

사용자 접점. 토큰 = 전기 콘센트. 가격↓ → 사용량↑ → 지능형 경제 가속. 차트의 4 자리수 가격 차이는 'AI as utility' 비유의 핵심.

📈 연도별 성능↑ + 가격↓ — 두 추세선

파란 실선 = 매년 발표된 최고 MMLU 점수 (성능 한계, 좌측 축) · 주황 점선 = MMLU≥80 모델 중 출력 가격 최저값 (가성비 한계, 우측 log 축). 성능은 매년 상승하고, 가격은 2024년 75× 폭락 후 한 자릿수에서 안정화.

📊 두 추세선 해석
  • 📈 파란 실선 (최고 MMLU): 매년 발표된 최강 모델의 점수 — 2022년 70점 → 2026년 94.5점 (24.5pt ↑)
  • 💰 주황 점선 (가성비 한계): MMLU≥80 모델 중 출력 가격 최저 — 2023년 $30 → 2024년 $0.40 (75× ↓) 후 안정화
  • 두 축의 의미: 왼쪽=성능 한계 (높을수록 좋음), 오른쪽=가격 (log scale, 낮을수록 좋음)
  • 2024 가격 floor 돌파: open-source 약진 (Gemini 2.0 Flash · Llama 3.3 · DeepSeek V3) 으로 가성비 한계가 한 자릿수로 진입
  • 2025-2026 plateau: 가성비 floor 는 안정화됐고, 최고 성능은 계속 상승 — 같은 가격으로 더 강한 모델

📊 모델별 출시 시점 가격 추세 (USD per 1M tokens, log scale)

가격 종류:
📊 데이터 해석 가이드
  • 로그 Y축 — 가격 범위가 $0.07 → $150/M 으로 4 자리수 차이가 나기 때문
  • 점 = 모델 출시, 라인 = 같은 provider 의 시간 추이
  • 출력 가격 이 input 의 3-5배 — 표준 (모델은 출력 토큰 1개당 더 많은 compute 사용)
  • 2022-2025 추세: GPT-3.5 turbo 출력 $20/M (2022) → GPT-4o-mini 출력 $0.6/M (2024) ≈ 33×↓
  • 예외: o1 / Opus / GPT-4.5 — frontier reasoning · 큰 컨텍스트 모델은 가격 정체 또는 상승

⚖️ 가성비 Pareto frontier — MMLU 성능 vs 출력 가격

X = MMLU 점수 · Y = 출력 가격 (log) — 오른쪽 아래 = 가성비 최고. 연도별 frontier (점선) 가 시간이 지나며 아래로 이동 = 같은 성능을 더 싸게 살 수 있게 됨. 예: 2024 GPT-4o-mini (82 MMLU, $0.6/M) · 2025 DeepSeek-V3 (88.5 MMLU, $1.10/M).

색상:
📊 가성비 Pareto frontier 해석
  • 축 의미: X = MMLU 성능 (오른쪽일수록 우수) · Y = 출력 가격 (아래쪽일수록 저렴) — 오른쪽 아래 = 가성비 최고
  • Pareto frontier (점선): 각 연도에서 같은 성능 구간 최저가 모델만 연결. 시간이 지날수록 frontier 가 오른쪽 아래로 이동 = 가성비 향상
  • 2022 → 2026 추이: GPT-3.5 (70 MMLU, $20/M) → GPT-4o-mini (82 MMLU, $0.6/M) → DeepSeek-V3 (88.5 MMLU, $1.10/M)
  • provider 색상 모드: 같은 provider 의 모델들이 어떻게 자기 line up 을 늘렸는지 확인
  • 이 차트는 시간이 아닌 성능 vs 가격 의 Pareto 관점 — 위쪽 차트 (출시일 vs 가격) 와 다른 정보를 보여줍니다

Intelligent Economy

AI 가 2030년 글로벌 GDP $7-15조 추가 기여 추정 (McKinsey/Goldman).

📍 현황

2025 민간 AI 투자 $345B (Stanford). H2 2025 기업 AI diffusion 30%+. AI talent concentration LinkedIn 기반 미·인·이스라엘 상위.

McKinsey: 2030년 GDP 기여 $7T+. Goldman: 노동 생산성 1.5%↑/년. 일자리 영향 양면 — 자동화 vs 신규 직업.

스택의 최종 결과. 1-5 레이어 모두 효율적이어야 GDP·생산성 효과 발현. 한국은 투자·인재 양 측면 가속 필요.
