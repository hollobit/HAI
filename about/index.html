hai — AI Index Dashboard

hai 는 Stanford HAI 가 매년 발행하는 AI Index Report (2024 · 2025 · 2026) 의 ~979 figure 와 본문을 한국 중심 관점으로 재구성한 정적 대시보드입니다. "AI 3강 한국" 가설을 정량 평가하고, 외부 인덱스 (Tortoise · Oxford · McKinsey · IEA 등) 와 대조하며, 실시간 시뮬레이터로 정책 시나리오를 탐색할 수 있습니다.

무엇을 제공하나요

  • 9 챕터 보고서 narrative — 한국어 요약 + 영문 verbatim 인용 (grep 검증)
  • 335 figures 자동 시각화 — 83% 차트 마운트, 100% per-figure 페이지
  • AI 3강 스코어카드 — 9 차원 SWOT 분석 + 20 차원 확장 시뮬레이터
  • 12국 비교 — 한국 · 미·중·일·독·영·프·캐·호·인·싱·UAE × 9 차원 레이더 + 격차 분석
  • AI 6-레이어 스택 — 전력망 → 컴퓨팅 → 클라우드 → 모델 → 토큰 → 지능형 경제
  • 2027-2030 전망 — log-linear 외삽 + 한국어 narrative
  • 판본 드리프트 — 2024/2025/2026 같은 지표가 어떻게 재계산됐는지

라이선스

  • Stanford HAI AI Index Report 본문 + figure — CC BY-ND 4.0 (인용 가능, 변형 금지)
  • 외부 출처 (Tortoise · McKinsey · IEA · Goldman 등) — 메타데이터 + 출처 링크만, 원수치 미포함
  • hai 자체 코드 + 한국어 narrative + 시각화 — MIT (개인용 자유, 상업 사용 시 출처 표기 권장)
  • Stanford HAI 공식 데이터 가 아닌 외부 추정 (예: McKinsey GDP 기여, IEA 데이터센터 전력) 은 출처 명시 + "내부 시뮬레이션" 배지로 구분

기술 스택

  • Pipeline — Python 3.12 + uv + Pydantic v2 + typer + Claude Sonnet 4.6 (narrate)
  • Web — Astro 6 + React 19 Islands + MDX + Recharts + TypeScript strict
  • Deploy — gh-pages-only (소스 비공개, 빌드 산출물만 push)
  • Test — 130+ pytest, 76+ vitest (Python ↔ TS parity 픽스처)
  • Quality gates — verify-live (HTTP 200) · check-bundle-size · check-reproducibility
